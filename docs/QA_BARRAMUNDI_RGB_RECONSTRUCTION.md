Owner authorized autonomous experiment on uploaded BarramundiFish.glb. Executed locally in Linux CPU Python with NumPy/SciPy/Numba/trimesh/scikit-image/VTK, separately from A3DS core. No Blender or external generator. Reference renderer uses original transformed mesh/UV/base-color image; reconstruction uses only calibrated RGB renders and silhouette masks, not source triangles or texture maps. Original bounds supply normalization/scale and original mesh is reused solely for validation.
