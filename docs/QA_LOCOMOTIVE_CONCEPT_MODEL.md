# Locomotive concept modeling — local experiment
Owner supplied a three-view concept collage and requested an actual 3D model. Source SHA256 2cd6d9cc482e8155a1c301a0d7d9aea2dc1a85154cd53b574fb7b58b4a17bd81.
Created a standalone parameterized Python/trimesh model, not blind RGB reconstruction and not integrated with A3DS core. VTK offscreen renders of the actual generated mesh: hero, side, top, front, rear. Two iterations; reduced pantograph height and bogie lateral projection after comparing first render with concept. Body has a UV-painted red stripe, dark solid nose panel without an additional windshield, blunt rear, separate roof equipment, two bogies, four axles, lamps and detachable pantograph.
Exported GLBs reopened locally: complete scene 379 meshes, 36,640 triangles; body 331 meshes, 32,080 triangles; pantograph 48 meshes, 4,560 triangles. Same origin, glTF Y-up, art units not metric. No nonfinite vertices or degenerate triangles detected. Hull with its caps is watertight and winding-consistent after welding seam vertices for QA; full multi-part assembly is not a single solid. 2048x1024 body texture verified after readback. Full GLB SHA256 ea0ec0fadab6ffcc6a10ff5eaea5004a03226995120cc32cee242195b5b34d06.
Actual comparison renders, GLBs, source and metrics delivered via chat archive. Not calibrated projections, no quantitative fidelity claim; invisible surfaces and details inferred, materials approximate. No Factorio sprite export or native game test. No production code changes, Stage 05, merge, release or Factorio repository edits.
