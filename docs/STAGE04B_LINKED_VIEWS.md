# Stage 04B — linked views
Run `python -m a3ds.linked_editor` with Tk installed. Four views render one shared native A3DS loft. Left drag colored handles in orthographic views; release commits the validated edit to shared history and redraws all views. Orange centers, cyan half-width, green half-height. Front handles target foremost section only. Hero left drag orbits; wheel zooms hero. Orthographic views use fixed camera scales. Undo/redo operate on geometry, not camera or overlay state. Right click an orthographic viewport to load a prealigned transparent 420x300 PNG overlay; opaque pixels obscure the model. Overlay is transient, not saved or automatically calibrated. Grid spacing 1 BU. Save JSON or export GLB. No external rendering backend.

Acceptance: run regression tests including coordinate signs, invalid edit rejection and undo/redo. Manually exercise Tk on Windows, check handle selection and redraw, overlay transparency, save/reopen, GLB and camera interaction. GUI acceptance remains NOT_RUN. Drag preview is a cursor ghost, not live mesh deformation; geometry updates on release. No general mesh editing, dynamic framing, automatic calibration or agent RPC yet. Session API is usable by Python agents in-process; no concurrent mutation guarantee. No main merge, release or Factorio modifications.
